# smol.pub

## O que é

Serviço de **diário/journal** para a "small web", com interface web simples para publicar posts. Alimenta o site [smol.pub](https://smol.pub).

## Para que serve

Publicar um journal pessoal acessível via Web, Gemini e Gopher simultaneamente — sem depender de plataformas centralizadas.

## O que faz

- Publicação em **Web, Gemini e Gopher** em paralelo
- CRUD de posts, páginas estáticas, header/footer customizáveis
- Temas e personalização visual
- Upload de arquivos, exportação, feeds RSS/Atom
- Multi-domínio com certificados TLS automáticos em produção

## Tecnologias

Go 1.16, PostgreSQL, Gorilla, `go-gemini`, `go-gopher`, TLS/autocert

## Funcionalidades principais

- Journal multi-protocolo
- Temas e customização
- TLS automático
