# piclog

## O que é

Plataforma web para **upload e compartilhamento de fotos JPEG**, com perfis de usuário e feed público.

## Para que serve

Hospedar um photolog pessoal ou comunitário — compartilhar imagens com amigos de forma simples, com perfis customizáveis e feed RSS.

## O que faz

- Registro, login, ativação e reset de senha por e-mail
- Upload com compressão agressiva de JPEG
- Perfis com CSS customizável
- Feed RSS (`feed.php`)
- Widget embutível, paginação, admin e moderação

## Tecnologias

PHP, MySQL, PHPMailer

## Funcionalidades principais

- Photolog com upload e compressão
- Perfis personalizáveis
- Feed RSS e widget embed
