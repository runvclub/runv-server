# ichipedia

## O que é

**Wiki estática** de referência sobre o ecossistema Ichi e a "small web", com artigos escritos em **gemtext** (`.gmi`) e publicados como HTML.

## Para que serve

Documentar conceitos, projetos e protocolos da small net (Gemini, Gopher, Ichi, midnight.pub, m15o, etc.) num formato leve e legível.

## O que faz

- Mantém artigos em `src/*.gmi` com links wiki `[[...]]`
- Gera HTML estático em `public/`
- Usa template HTML (`template.html`) e changelog
- Descreve o próprio ecossistema em `src/ichipedia.gmi`

## Tecnologias

Gemini/gemtext (`.gmi`), HTML estático

## Funcionalidades principais

- Artigos enciclopédicos sobre a small web
- Links cruzados entre páginas
- Publicação estática (sem backend em runtime)
