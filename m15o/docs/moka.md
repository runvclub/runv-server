# moka

## O que é

Editor/wiki **client-side** num único arquivo HTML — cria e publica páginas localmente, sem backend.

## Para que serve

Permitir escrita e organização de notas/wiki no navegador, com armazenamento em `localStorage`, ideal para quem quer privacidade e simplicidade sem servidor.

## O que faz

- Editor multi-painel com redimensionamento
- Sintaxe gemtext-like + links wiki `[[...]]`
- Armazena dados em `localStorage`
- Modo visualização/edição com routing por hash (`#pagina`)
- Import/export e download de HTML publicado
- Calcula backlinks entre páginas

## Tecnologias

HTML, CSS, JavaScript (vanilla) — arquivo único `moka.html`

## Funcionalidades principais

- Wiki local sem servidor
- Multi-painel editável
- Export para HTML estático
