# 15f

## O que é

Interpretador e runtime de uma linguagem de programação estilo **Forth** com extensão `.15f`, capaz de desenhar gráficos na tela via SDL2.

## Para que serve

Experimentação com linguagens minimalistas e programação visual de baixo nível. Permite escrever scripts que manipulam uma pilha de valores e emitem saída gráfica — útil para aprender paradigmas Forth-like e prototipar demos visuais simples.

## O que faz

- Interpreta arquivos `.15f` com primitivas Forth (pilha, variáveis, loops)
- Renderiza na tela via SDL2 (`emit`, `clr`, etc.)
- Inclui biblioteca padrão em `std.15f`
- Compila com `build.sh` a partir de `src/main.c`

## Tecnologias

C (C89), SDL2

## Funcionalidades principais

- Parser e interpretador Forth-like (`interpret.c`, `runtime.c`, `stack.c`)
- Primitivas gráficas e de controle de fluxo (`do`/`loop`, variáveis)
- Exemplos como `hello-world.15f`
