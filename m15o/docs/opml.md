# opml

## O que é

Biblioteca **Go** para trabalhar com listas de assinaturas **OPML** (feeds RSS).

## Para que serve

Importar e exportar listas de feeds RSS/Atom no formato OPML — usada como dependência do `owl-report`.

## O que faz

- Faz parse de XML OPML
- Extrai recursivamente outlines do tipo `rss`
- Retorna `[]Subscription` com título e URL

## Tecnologias

Go 1.18

## Funcionalidades principais

- Parse de OPML
- Extração recursiva de assinaturas
- API em `opml.go`
