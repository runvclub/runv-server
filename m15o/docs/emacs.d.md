# emacs.d

## O que é

Configuração pessoal do **Emacs** com modos e atalhos customizados para o ecossistema m15o — HTML Blog, gemtext, journals e Gopher.

## Para que serve

Unificar a edição de conteúdo da "small web" dentro do Emacs: blogs HTML, journals, gemtext e navegação Gopher, com interface minimalista e atalhos de produtividade.

## O que faz

- Carrega modos customizados para formatos do ecossistema m15o
- Integra cliente Gopher via `elpher.el`
- Define atalhos para comandos shell, data, bookmarks e janelas
- Aplica tema visual minimalista (sem menu/barra, fundo creme)

## Tecnologias

Emacs Lisp

## Funcionalidades principais

- Modos: `m15o-html`, `m15o-gmi`, `html-journal`, `m15o-highlight`, `m15o-surround`
- Cliente Gopher integrado
- Ponto de entrada: `init.el`
