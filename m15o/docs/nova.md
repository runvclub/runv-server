# nova

## O que é

**Navegador gráfico desktop** para o protocolo **Nex** — cliente GUI com histórico de navegação.

## Para que serve

Navegar em estações Nex com interface gráfica, exibindo texto e imagens, com botões voltar/avançar/subir — alternativa visual ao cliente de terminal `rex`.

## O que faz

- Conecta a hosts Nex na porta 1900
- Exibe conteúdo de texto e imagens (JPEG/PNG)
- Navegação com histórico (voltar, avançar, subir diretório)
- Parsing de links clicáveis no conteúdo

## Tecnologias

Object Pascal / Lazarus (Free Pascal)

## Funcionalidades principais

- Cliente Nex com GUI
- Suporte a imagens inline
- Histórico de navegação
