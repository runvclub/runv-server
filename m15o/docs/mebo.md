# mebo

## O que é

Sistema simples de **fórum / message board** para discussões em threads.

## Para que serve

Hospedar discussões online leves com threads, respostas aninhadas e moderação — alternativa minimalista a fóruns tradicionais como phpBB.

## O que faz

- Cria threads e respostas aninhadas
- Suporta threads sticky e roles (visitor/member/admin/suspended)
- Registro com ativação por e-mail e reset de senha
- Feed RSS/Atom (`feed.php`)
- Moderação admin e gestão de contas

## Tecnologias

PHP, MySQL, PHPMailer

## Funcionalidades principais

- Fórum com threads e respostas
- Sistema de roles e moderação
- Feeds RSS/Atom
