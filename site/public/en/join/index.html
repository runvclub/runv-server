Request an account

Access is by SSH key only. There is no web sign-up and no password. The request takes about 5 minutes, followed by manual review.

1. Generate a key pair

Linux and macOS:

ssh-keygen -t ed25519 -C "your-email-or-host" -f ~/.ssh/id_ed25519_runv
cat ~/.ssh/id_ed25519_runv.pub

Windows (PowerShell). If ssh -V fails, install OpenSSH Client under Settings > Apps > Optional features.

ssh-keygen -t ed25519 -C "your-email-or-host" -f $env:USERPROFILE\.ssh\id_ed25519_runv
Get-Content $env:USERPROFILE\.ssh\id_ed25519_runv.pub

the file without .pub is the private key: never send or share it

2. Connect to entre

ssh -i ~/.ssh/id_ed25519_runv entre@runv.club

On first connection, check the host and accept the fingerprint. The terminal form asks for a username, email, online presence (optional) and the public key (contents of the .pub file). The form is available in English.

3. Review

The queue is reviewed manually. Once approved, the account is created and confirmation is sent by email. From then on:

ssh -i ~/.ssh/id_ed25519_runv USERNAME@runv.club

Requirements

  • Username: 2 to 32 characters, lowercase letters, digits, _ and -, starting with a letter.
  • Ed25519 key (preferred). ECDSA and RSA are accepted according to server policy.
  • A valid email address for confirmation.
  • Agreement with the rules.

Issues with a request: admin@runv.club. FAQ at /en/faq.
